# Hedwiq: Agentic Meeting Application

## Overview

Hedwiq is an **agentic meeting app**, a modern alternative to Zoom and Google Meet with a deep focus on native AI agents. Unlike platforms that rely on visible bots or external extensions, Hedwiq is a **fully native agentic web application**, where AI works seamlessly behind the scenes.

## Key Features

### 1. Real-time Transcription

* A right-hand sidebar displays real-time transcription of each participant.
* Speaker differentiation is handled through formatting and color labeling.
* No bots, plugins, or setup required — everything is built directly into the web client.

### 2. Real-time Insights

Hedwiq doesn't just transcribe — it **analyzes conversations live**. The AI agent identifies key elements of the discussion and displays them directly inside the transcription stream using specialized UI components.

The AI automatically detects and highlights:

* **Idea** — new ideas or suggestions
* **Problem** — issues, challenges, pain points
* **Solution** — proposed solutions
* **Risks** — risks, limitations, uncertainties
* **Insights** — meaningful observations
* **Hypothesis** — hypotheses and assumptions
* **Action item** — tasks requiring follow-up
* **Open question** — unresolved questions needing attention

Each of these elements appears as structured UI blocks such as badges, cards, or mini-highlights within the transcript.

### 3. Notes Auto-Completion

The AI agent continuously generates and updates real-time notes:

* automatically clusters related insights
* connects elements into meaningful groups
* creates concise summaries without user intervention

This transforms a standard meeting into a dynamic working session where all essential details are captured automatically.

## Why Hedwiq?

* Native agentic core with no intrusive bots
* Full transparency and clarity throughout the meeting
* Smart insights instead of raw text transcripts
* Productivity boost with zero extra effort for users

Hedwiq turns every meeting into a knowledge engine — not just a conversation.
